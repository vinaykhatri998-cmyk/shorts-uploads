Privacy Policy

How It Evolved Uploader is used only by the owner of the How It Evolved YouTube channel to upload that channel's own videos.

It requests the YouTube upload permission (youtube.upload) for the owner's account only. It does not collect, store, sell or share data about any other user. It reads no personal data; it only sends video files and their titles, descriptions and tags to YouTube.

The access token is stored as an encrypted secret and can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs follows the Google API Services User Data Policy. This app uses YouTube API Services; see the Google Privacy Policy.

Contact: via the How It Evolved channel page.
